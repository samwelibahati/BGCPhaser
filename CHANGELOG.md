# Changelog

## 0.1.0 — 2026-08-24

Initial public release of BGCPhaser.

- assembler-oriented graph representation and bounded walk utilities;
- candidate transition construction and sequence spelling;
- direct-read, paired-linkage, coverage and assembler-path evidence;
- intrinsic antiSMASH NRPS/PKS chemistry extraction;
- frozen 12-decimal sequence-plus-chemistry scoring and competition ranking;
- end-to-end `bgcphaser analyse` and feature-only `bgcphaser rank` commands;
- public unit/regression tests and GitHub Actions verification.
